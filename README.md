# Molly Doshi — Portfolio

Portfolio site for Molly Doshi, a UI/UX designer. Built with TanStack Start, React, TypeScript and Tailwind CSS, and deployed to Cloudflare Pages. There is no backend.

## Development

```sh
npm install
npm run dev
```

Place the site artwork in `public/assets/` (see `src/lib/assets.ts` for the expected filenames).

## Deploy (Cloudflare Pages)

```sh
npm run deploy
```

Or connect the repo in the Cloudflare dashboard with build command `npm run build` and output directory `dist`.
